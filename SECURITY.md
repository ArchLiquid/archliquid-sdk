# Security policy

Please report suspected vulnerabilities privately through GitHub’s private
vulnerability reporting flow when available. If that flow is unavailable,
contact `hello@archliquid.com` and avoid opening a public issue with exploit
details.

SDK users must treat RPC data and quotes as untrusted until strict decoding and
identity validation succeed. Build complete instructions locally, simulate the
final transaction against a fresh blockhash and context slot, and keep wallet
signature approval human-controlled.
